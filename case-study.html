The Brief & Project Overview

ICT-NEXA is a comprehensive IT service & application management platform developed for Kalla Institute of Technology and Business. As part of my undergraduate thesis at Universitas DIPA Makassar, I designed the user interface and user experience (UI/UX) using a human-centered Design Thinking framework (Empathize, Define, Ideate, Prototype, and Test).

The goal was to streamline academic and administrative IT requests, application registration, and issue resolution into a single, cohesive, modern interface accessible to students, faculty, and administrators.

"Developing an intuitive digital ecosystem requires starting with empathy — understanding how students and academic staff interact with daily IT services."

Design Thinking Methodology

1. Empathize & Define

Conducted user interviews, observational studies, and survey questionnaires with academic users at Kalla Institute to identify core pain points in existing service request workflows.

2. Ideation & Wireframing

Structured the user architecture around 6 essential application views: authentication, dashboard statistics, application listing, application registration, answer/ticket response system, and user profile management.

Key Design Principles

Consistent Visual Hierarchy

Established a standardized UI component system built in Figma, ensuring typography, spacing, active states, and color palettes stay consistent across all 6 key screens.

Streamlined Navigation

Reorganized the service workflow to reduce user clicks when submitting application requests or tracking support responses, resulting in a cleaner user journey.

Conclusion & Impact

This design case study formed the foundation of my S1 Informatics Engineering thesis at Universitas DIPA Makassar (Graduated Cum Laude with 3.85 GPA). The resulting UI design demonstrated how structured UX research and Design Thinking deliver a seamless digital service environment for academic institutions.
